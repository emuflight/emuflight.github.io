# Parameter List

CLI parameter reference for each released EmuFlight version, auto-generated from `settings.c` on the corresponding `*-maintenance` branch. These branches are frozen and will not receive further releases, so each page reflects exactly what shipped.

An [**0.5.0 (Preview)**](0.5.0) page is also available, generated ahead of time from the current `master` development branch — not a released version, and subject to change before 0.5.0 actually ships.
